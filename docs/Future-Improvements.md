# Future Architecture Roadmap

## Suggested Features
1. **Multi-Camera Sync**: Correlate vehicle travel times across multiple cameras to detect average speed infractions.
2. **Additional Violation Types**: Implement detection for distracted driving, tailgating, and noise level violations.
3. **Scalable Stream Processing**: Replace the local video reader with Apache Kafka video streaming pipelines for large-scale operations.
4. **Government Database Integration**: Connect to national vehicle registries (e.g., VAHAN API) for automated owner verification.
