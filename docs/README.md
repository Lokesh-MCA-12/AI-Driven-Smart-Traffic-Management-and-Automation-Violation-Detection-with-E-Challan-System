# 🚦 AI-Driven Smart Traffic Management and Automated Violation Detection with E-Challan System

![System Preview](../Demo%20Video-AI-Driven%20Smart%20Traffic%20Management%20and%20Automation%20Violation%20Detection%20with%20E-Challan%20System.mp4)

An enterprise-grade, state-of-the-art AI-powered traffic control, safety monitoring, and automated law enforcement platform. It uses advanced computer vision and Deep Learning algorithms to detect vehicles, calculate traffic density, identify traffic rule violations in real-time, perform Automatic Number Plate Recognition (ANPR), and issue automated E-Challans.

## 🛠 Tech Stack Overview
* **AI/CV Engine**: Python 3.11, OpenCV, YOLO26, EasyOCR, SORT Tracker
* **Backend API**: FastAPI, SQLAlchemy Async, Pydantic v2
* **Database**: PostgreSQL 15+
* **Frontend Web Dashboard**: React 18, Vite, Tailwind CSS, Chart.js 4
* **Gateways & Infrastructure**: Razorpay (Payments), Twilio (SMS), SMTP (Email), Docker & Nginx
